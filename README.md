
# ScientificCalculator

A menu-driven scientific calculator built with C++.

## Features
- Addition, subtraction, multiplication, and division
- Exponentiation and square root
- Sine and cosine using degree inputs
- Division-by-zero validation

## Technologies
- C++
- cmath library
- Switch statements and functions

## Run
Compile: `g++ main.cpp -o calculator`
Run: `./calculator` (Windows: `calculator.exe`)
